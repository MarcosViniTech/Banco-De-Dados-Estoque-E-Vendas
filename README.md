# Banco de Dados de Estoque e Vendas

Projeto de banco de dados desenvolvido para uma **empresa fictícia do setor de tecnologia**, com foco no controle de estoque e vendas. O projeto foi desenvolvido para praticar conceitos de **modelagem de dados e desenvolvimento de bancos de dados** estudados ao longo do semestre.

## 🛠️ Tecnologias

* SQL
* MySQL

## 📚 Conhecimentos praticados

* Modelagem conceitual de dados
* Diagrama Entidade-Relacionamento (DER)
* Identificação de entidades e atributos
* Definição de chaves primárias (PK)
* Definição de chaves estrangeiras (FK)
* Relacionamentos entre entidades
* Cardinalidade dos relacionamentos
* Criação e estruturação de tabelas
* Definição de tipos de dados
* Implementação de banco de dados utilizando scripts SQL
* Inserção de dados com `INSERT`
* Consultas com `SELECT`
* Consultas utilizando `INNER JOIN`
* Filtragem de dados com `WHERE`
* Ordenação de resultados com `ORDER BY`

## 🗃️ Estrutura do Banco

O banco de dados possui 5 entidades principais:

* **categoria** — categorias dos produtos
* **fornecedor** — informações dos fornecedores
* **produto** — produtos e controle de estoque
* **venda** — registros das vendas
* **item_venda** — itens relacionados às vendas

## 🔎 Consultas

Foram desenvolvidas consultas para:

* Listar produtos e suas respectivas categorias
* Consultar produtos e seus fornecedores
* Relacionar produtos às vendas realizadas
* Identificar produtos com baixo estoque

## 🎯 Objetivo

Aplicar na prática os conhecimentos de **modelagem e desenvolvimento de bancos de dados**, desde a elaboração do modelo conceitual e DER até a implementação em SQL, inserção de dados e realização de consultas.

> Projeto desenvolvido para fins de estudo e portfólio.
